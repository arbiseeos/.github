# ArbiSee 👋 Open Source

[**ArbiSee OS**](https://os.arbisee.com) is where ArbiSee builds, shares, and maintains open-source software.

We create practical tools, libraries, services, infrastructure, and experiments that help people **build**, **automate**, and **operate better**.

## What we Build

Our projects explore practical solutions across software and technology, including:

- **Developer tools**: Libraries, utilities, SDKs, and tools that make development easier.
- **Automation and workflows**: Tools that reduce repetitive work and improve how processes run.
- **Infrastructure**: Services, middleware, and components that help software systems operate better.
- **Business utilities**: Practical tools for everyday business and operational problems.
- **Experiments**: Ideas and technologies we're exploring in the open.

> Some projects may grow into products. Others may simply exist because they are useful.

## Getting involved

Found something useful? Have an idea? Want to help improve a project? There is a lot to do!

- **Explore** a project and see what we're building.
- **Try** it, test it, and tell us what works — or what doesn't.
- **Discuss** ideas, problems, and possible improvements.
- **Report** bugs or suggest features.
- **Contribute** code, documentation, tests, examples, or anything else that makes a project better.

Start with the repository you're interested in and check its contribution guidelines, issues, and discussions.

## Help us making this Community safe ☂️

ArbiSee OS follows the [Contributor Covenant **Code of Conduct**](../CODE_OF_CONDUCT.md). Please abide with this **Code of Conduct** when interacting with all repositories under the ArbiSee OS umbrella and when interacting with people.

## Reporting Security Issues

Please be mindful that security-related issues should be reported through coordinated disclosure ([learn how](../SECURITY.md)) as security-related issues and vulnerabilities can be exploited and we request confidentiality whenever possible.
